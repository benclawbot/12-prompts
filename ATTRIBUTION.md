# Attribution

The idea of organizing a collection of 12 reasoning frameworks was inspired by [hskelp9527-pixel/twelve-prompts](https://github.com/hskelp9527-pixel/twelve-prompts). That repository credits **@Khazix0918** for the original Chinese prompt texts and says its packaging and routing were done by the repository curator.

This project is an **independent English adaptation of the 12 framework concepts**, with newly authored prompts, selection rules, examples, quality safeguards, packaging and tests. It does **not** contain the original prompt texts or a verbatim translation. No affiliation with or endorsement by the original author or curator is claimed.

If you want the original exact Chinese wording, consult the upstream repository and its attribution and reuse guidance.
